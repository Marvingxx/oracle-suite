Oracle Suite portable mode

While this file sits next to oracle-suite.exe, Oracle Suite keeps its settings, its
download cache and its record of installed apps in the OracleSuiteData folder beside it, and
writes nothing to %APPDATA%. Copy the whole folder to move Oracle Suite with its settings.

Delete this file to use the normal per-user settings folder (%APPDATA%\Oracle Suite) instead.
If OracleSuiteData can't be written (for example on a read-only drive), Oracle Suite says
so and uses %APPDATA%\Oracle Suite instead.
